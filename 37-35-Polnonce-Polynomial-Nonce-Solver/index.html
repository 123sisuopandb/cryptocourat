35. Polnonce (Polynomial Nonce) Solver

Detect and exploit nonces generated via Linear/Polynomial patterns (LLL Lattice Reduction).

Instructions:
If the random number generator (RNG) used for 'k' is weak (e.g., LCG or increments), signatures become linked.
1. Enter RSZ lines from multiple transactions of the same address.
2. The tool will check for linear relations and generate a high-performance LLL exploit script.
