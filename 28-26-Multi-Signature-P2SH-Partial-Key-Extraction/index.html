26. Multi-Signature (P2SH) Partial Key Extraction

Breakdown and extract Public Keys hidden inside a P2SH Multi-Sig script

Instructions:
A P2SH Multi-Signature address hides its participants. However, when the coins are spent, the 'Redeem Script' is revealed on the blockchain. 
1. Paste the Raw Hex of the Redeem Script.
2. The tool will parse the script mathematically, determine the 'M-of-N' rules, and extract every single participant's Public Key.
3. You can then use these Public Keys to trace individual identities or further target them.
