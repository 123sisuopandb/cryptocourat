58. Address / RSZ → Bit-Leak Deep Analyzer

Two workflows: (A) Enter a Bitcoin address + count → tool fetches transactions, extracts every R:S:Z, prints them in full, then runs the full pipeline. (B) Paste R:S:Z lines directly and skip fetching. Both paths run: same-r reuse scan, r-value bit distribution, LLL Boneh–Venkatesan sweep, and — after key recovery — full k reconstruction with per-signature MSB/LSB bit-leak proof. Every intermediate value is printed in full (no truncation).

▸ MODE A — Fetch from Address
▸ MODE B — Direct R:S:Z Input (skip fetching)
Small-k Intersection: for each signature enumerates candidate d values from guessed k bit-patterns (0..BIAS bits), then intersects across sigs. Matches Python "possible private key" scripts. Use a single number in BIAS (e.g. 125) to sweep k bit-length 1..125.
e.g. 125 = attack exactly 125-bit k · 4-12 = sweep · 1-256 = full brute
leave auto — tool picks m = min(sigs, 40)
SMALL-k INTERSECTION automatically runs: (1) public-key recovery from R:S:Z, (2) same-r reuse scan, (3) MSB-stuck-bit patterns, (4) LSB-stuck-bit patterns, (5) MSB+LSB mixed patterns, (6) power-of-two candidates — then intersects across signatures to find the true private key.
