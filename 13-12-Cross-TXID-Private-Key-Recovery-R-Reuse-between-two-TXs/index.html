12. Cross-TXID Private Key Recovery (R-Reuse between two TXs)

Instructions:
1. Enter two different TXIDs belonging to the same address.
2. The tool will extract R, S, Z, Public Key from both transactions inputs.
3. If it detects the same R-Value across any input between the two TXIDs, it will calculate the Private Key using the ECDSA formula.
