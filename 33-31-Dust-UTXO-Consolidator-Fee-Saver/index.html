31. Dust UTXO Consolidator (Fee Saver)

Clean up many small balances (dust) into a single address while minimizing network fees.

Instructions:
1. List all Private Keys holding small amounts of BTC.
2. Provide a single target address where you want to pool the funds.
3. Set a low fee rate to save money.
The tool will fetch UTXOs for ALL keys and build one optimized transaction.
